# 老球場走讀

目前首頁改為一個可操作的球場展場。這份說明描述實作行為，不表示已完成瀏覽器驗收。

1. 點拱門「撕票，走進球場」或「撕票入場」，經推進轉場進入看台。減少動態設定下直接入場。
2. 點場景標記或四個站點自由移動。場景取得焦點時，可用左右方向鍵切換站點。環顧、靠近與退後會改變鏡頭，日夜按鈕改變光線。
3. 看台呈現所選年份的精選球票；有相關照片時可點圖閱讀圖說。開故事使用原本含來源的詳情視窗，不把虛構場景寫成歷史事實。
4. 記分板可拖年份及快捷跳年，同步更新場景遠方記分板、年度隊數、冠軍及觀眾摘要。年度數據直接讀取既有 seasonRecords，2026 不補造全年數據。
5. 球員通道呈現當年的球衣。每件為自製辨識圖案，非官方球衣；點選即開啟同一份球隊沿革資料。季中更名合併呈現，台灣大聯盟僅於 1997–2002 顯示，與 CPBL 分組。
6. 放映室包含原本三集緯來影片。選集才載入，不自動播放；離開房間或前往完整資料庫時移除播放器。file:// 的啟動指引仍保留，線上影片需從本機 HTTP 或網站網址開啟。
7. 四站到訪紀錄只記錄本次開啟。返回入口或切換房間不會清除年份、篩選、已讀球票或測驗進度。
8. 原有年度表格、所有事件、搜尋、測驗、來源與打擊遊戲收在下方可展開的完整史料庫；場內入口可以直接展開並定位。

本頁是原創記憶展場：外觀參考臺北市立棒球場，場內採藝術詮釋，並非建築精確復原。選擇 2001 年以後的年份是在同一展場查閱後續歷史，沒有表示老球場仍在當年存在。網站已顯示此說明。
