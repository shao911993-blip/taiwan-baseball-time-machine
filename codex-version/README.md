# 臺灣職棒時光機

一張球票，走進臺灣職棒的時光。

## 開啟

**要在網頁內看影片：雙擊「啟動網站.cmd」**。它使用電腦上的 Node.js 啟動本機 HTTP 服務，並開啟瀏覽器；不必安裝任何 npm 套件。請保留啟動視窗，按 Ctrl+C 可關閉服務。預設網址為 `http://127.0.0.1:4173/#ballpark`，若連接埠已使用，啟動視窗會顯示實際網址。不會公開部署網站。

也可以在此資料夾執行 `node serve.cjs`，再開啟印出的網址。Node.js 不存在時，啟動檔會顯示安裝指引，沒有自動安裝程式。

離線查閱仍可直接開啟 **index.html**。HTML、CSS、JavaScript、資料、SVG 與圖片全部內嵌；外部史料及影片需要網路。HTML 約 9.3 MB，不必另帶圖片資料夾。直接以 `file://` 開啟沒有 HTTP 來源，YouTube 可能顯示錯誤 153；現在會改顯示啟動指引與原影片連結，不建立無法提供來源的播放器。

本次交付為本地版本，**尚未部署，沒有公開網址**。原有兩份規格檔未修改。

## 走進老球場

首頁改為球場走讀：點拱門推進入場，再從看台移動到記分板、球員通道與放映室。場景標記與下方站點都能操作；可環顧、靠近／退後、切換日夜燈光。記分板年份、當年球衣和原有資料庫共用狀態。看台球票打開原本的故事與來源，球衣打開球隊沿革；離開放映室會停止影片。

原本長篇的數據、完整事件、搜尋、測驗與打擊遊戲收進下方「完整史料庫」。詳細操作見 [WALKTHROUGH.md](WALKTHROUGH.md)，新場內插畫與實際提示詞見 [assets/WALKTHROUGH_PROMPT.md](assets/WALKTHROUGH_PROMPT.md)。場景是藝術詮釋的展場，並非歷史照片或建築精確復原。

## 已實作

- **棒球放映室**：緯來體育台《棒球故事挖古挖古》EP5、EP14、EP26，官方 oEmbed 已確認來源。選集後才嵌入播放器、不自動播放；可關閉及前往原影片。來源及播放限制見 VIDEO_SOURCES.md。

- **揮棒穿越**：按「投一球」，看準金色區域按揮棒或 Space。安打與甜蜜點有不同回饋，命中後揭開優先未讀的歷史球票；揮空可重試，也可直接抽票。命中／投球數只記錄本次頁面的小遊戲。
- **動態回饋**：來球、擊球飛出、命中文字、球票展開、年份切換、球隊卡片進場、觀眾數長條及故事視窗動畫。Escape、背景切換、手動切年或閱讀故事會取消來球；減少動態偏好預設靜態抽票。
- **真實照片與史料**：3 張總統府 CC BY 2.0 照片內嵌，可放大閱讀圖說、作者與授權，明確區分拍攝年份與事件年份。
- **年度數據與大事件**：1990–2025 共 36 年場次、總觀眾、平均觀眾、年度冠軍，可比較年份、切換圖表並看完整表格；另有歷史頭版與跨年事件篩選。2026 不填入未查核賽果。

- **球季轉播台**：37 個可點選年份柱，柱高呈現兩聯盟隊數；主動播放／暫停，支援逐年或只看事件年份、三種速度。開啟故事、手動切年、篩選、切到背景或按 Escape 都會暫停，抵達終點自動停止。
- **球隊變化提示**：比較上一個畫面與目前年份，分別呈現新出現、未列入及名稱階段改變；不將跨年比較直接解讀成加盟或解散日期。
- **探索路線與抽票**：三條路線直達兩聯盟、整合與六隊時代；抽票優先選未讀事件，24 張讀完後仍可重讀。已讀足跡可展開再訪，本次開啟期間保存。

- **年份穿梭**：1990–2026 共 37 年，預設 1990；滑桿、前後一年、年代按鈕共同更新單一狀態。上下限停用對應按鈕。
- **聯盟對照**：全部／中職／台灣大聯盟；並存時雙欄、窄螢幕上下排列。未參賽年份移除空名錄欄，只保留台灣大聯盟時期與首季／整合事件入口；1997–2002 才顯示雙聯盟完整對照。
- **完整年度名錄**：74 筆聯盟年度紀錄。1996 興農熊／牛、2003 那魯灣太陽／誠泰太陽、2000 臺中金剛冠名保留不同名稱但去重計數。
- **24 張歷史球票**：年份、聯盟與三類事件組合篩選；展開背景、影響、球隊與來源。清除篩選保留年份；空結果不宣稱當年沒有事件。
- **37 個球隊名稱階段**：搜尋涵蓋歷史球隊、TML 冠名與現存隊伍；台／臺可通用。每個階段附說明、時期、聯盟、來源與可切換沿革。
- **沿革關係**：更名、轉賣、冠名、解散後重新成立、多對一整併分開保存。臺北太陽＋高屏雷公→第一金剛；臺中金剛＋嘉南勇士→那魯灣太陽。
- **歷史挑戰**：12 題題庫隨機抽 5 題，每題四選一、每題 20 分；未選不能送出、同題不重複得分、解析及 0–100 分結果、重玩重置。
- **測驗回看**：調整年份及篩選、展開關聯事件，返回後保留題目、答案與分數。
- **可用性實作**：系統中文字型、可見焦點、原生滑桿、原生模態視窗、Tab 焦點循環、Escape 關閉、焦點返回、減少動態偏好、無自動音效。

## 資料口徑與查證

查核截止與來源查閱日期：**2026-10-16**。2026 年僅確認參賽名錄，不收錄未查核賽果或冠軍；未把整季視為已完成。

優先查閱中職沿革、官方協議新聞、球團隊史、國史館臺灣文獻館，並以中央社、自由時報、淡江大學台灣棒球維基館、政府典藏研究及同期舊聞補充。年度觀眾與冠軍彙整主要參考阿忠的職棒記錄網站，屬非官方彙整；早年統計存在不同版本，網站有標示，未宣稱全部為官方原始數據。2020、2021 平均值分母包括閉門比賽。照片授權見 assets/photos/ATTRIBUTION.md。每筆事件、球隊階段、沿革關係、年度名錄都有來源 ID；網頁的來源區保存機構、標題、網址及查閱日。

查證差異與限制已寫在網站「資料口徑與查證限制」：

- 官方兩個起始頁的完整擷取失敗，本版採可讀取的官方搜尋索引並交叉查核，沒有宣稱已讀到無法開啟的全文。
- 中職沿革表部分早年欄套用現今名稱，依當季名稱及其他史料修正。
- 一份 TML 冠名整理把誠泰贊助太陽寫成 2002 起；同期 2001-03-16 民生報及年度戰績確認 2001 已使用，採後者。
- 2000 臺中金剛冠名只確認至 5 月，確切日待補，沒有補造日。
- 味全 1999 解散、2019 重新加盟、2020 二軍、2021 一軍分開記錄。隊史冠軍可依官方合計，但不據此主張法人連續。
- 球隊字章、色彩為自製辨識元素；主視覺為參考老球場照片的 AI 生成建築插畫，不使用官方標誌，也不將生成圖當歷史照片。PNG 成品及實際提示詞保存在 assets；網站本身不依賴該目錄。

24 則事件是精選，並非完整逐年大事紀；一軍名錄不包括僅參加二軍的隊伍。部分史料網站有驗證頁或存取限制，外部連結能否開啟取決於來源網站。

## 實際驗證

有 Node.js 時，在此資料夾執行：

```text
node verify.cjs
node verify-server.cjs
```

本次執行通過 **1,783 個斷言及 30 項實際 HTTP 檢查**，涵蓋逐年名錄、組合篩選、資料關聯、測驗、圖片與編碼，以及照片授權、36 年數據、24 則事件、打擊時機／計分／靜態模式／取消來球，與轉播台的播放、暫停、速度、終點、事件年份、背景暫停、隨機未讀球票、足跡與路線跳轉。網頁檢查直接執行 index.html 內真正的 JavaScript，以最小 DOM 測試替身及可控制的計時器接收渲染與操作；不是瀏覽器測試。HTTP 檢查另實際啟動服務並發出請求，檢查回傳 HTML、UTF-8、Referrer-Policy、連接埠占用及路由。

**尚未完成的實機驗證**：環境的瀏覽器清單為空，Chrome 與內建瀏覽器開啟均回報不可用。因此尚未實際驗證 390px／1440px 排版與水平溢位、滑鼠觸控、原生鍵盤焦點、file:// 瀏覽器執行、瀏覽器主控台、外連逐一點開。已實作對應 CSS 與焦點處理，但不能視為已通過實機驗收。詳細清單見 [VERIFICATION.md](VERIFICATION.md)。

## GitHub Pages 公開步驟

1. 登入 GitHub，自行建立公開儲存庫，建議名稱 `taiwan-baseball-time-machine`。
2. 選 **Add file → Upload files**，把 `index.html` 上傳到 `main` 分支根目錄並提交。其餘文件可一起上傳，但不是網站依賴。
3. 前往 **Settings → Pages**。
4. 在 **Build and deployment → Source** 選 **Deploy from a branch**。
5. 選 `main` 分支及 `/ (root)`，按 **Save**。
6. 等待 Pages 建置成功，使用 GitHub 顯示的實際網址。一般格式為 `https://你的帳號.github.io/taiwan-baseball-time-machine/`，此格式只是說明，並非已部署連結。
7. 用該公開網址重做 VERIFICATION.md 的瀏覽器清單，再繳交網址與截圖。之後更新 `index.html` 並提交即可重新發布。
