# 臺灣職棒時光機

一張球票，走進臺灣職棒的時光。

一座可以自由走動的中華職棒博物館（1990–2026）：操作一個小球員在館內走動，參觀九個年代的動態展櫃、會變的球場模型、球隊族譜與冠軍獎盃牆，並親自體驗打擊、投球、主審、線審、壘審。

## 開啟

直接用瀏覽器開啟 **index.html** 即可，離線也能操作（外部史料連結需要網路）。

## 操作

- 鍵盤：方向鍵或 WASD 走動，靠近展品按 E／Enter 參觀，Esc 回到展廳
- 滑鼠／手機：點地板走過去（自動繞路），點展品會走過去並打開
- 右上角「館內地圖」可以直接前往任何展區；「集章」打開護照

## 館內配置

| 展區 | 展品 | 對應規格 |
|---|---|---|
| 入口大廳 | 入館畫面（網站名稱、首頁文案、選球衣）、服務台館長（集章護照）、館內地圖看板 | 首頁 |
| 歷史長廊 | 9 個年代動畫展櫃：球場模型自動播放，旗子落下、交棒翻面、兩隊整併成一面旗、觀眾增減、字幕，以及逐格出現的「傳承鏈」（例：俊國熊 → 興農熊 → 興農牛 → 義大犀牛 → 富邦悍將）；可暫停、上一幕、下一幕 | 故事主線 |
| 時光劇場 | 會變的球場模型＋年份控制台、聯盟篩選、自動播放；下方是當年數據、球隊卡與事件球票 | F01、F02、F04 |
| 隊史廳 | 球隊族譜（37 個隊名、整併與重新成立）、冠軍獎盃牆（1990–2025） | F03 |
| 球場體驗館 | 打擊練習、投球挑戰、主審、線審、壘審五個 canvas 小遊戲 | 互動體驗 |
| 資料室 | 問答館長（14 題抽 5 題，可回看歷史再返回）、書架（32 個來源與記錄方法） | F05、F06、§6 |

館內有參觀的球迷 NPC 會走動，靠近聊天會說一則小知識。逛完每一區可以集滿 19 個章。

### 球場體驗館

| 體驗 | 玩法 | 學到什麼 |
|---|---|---|
| 打擊練習 | 看準時機揮棒，好壞球可以選擇不揮，打到三出局 | 球數規則（四壞保送、兩好球後界外不三振）、球速 |
| 投球挑戰 | 選球種（直球、滑球、曲球、變速球），點位置投球，AI 打者決定揮不揮 | 球種特性與配球 |
| 主審 | 球進手套後 3 秒內判好球／壞球，判完用放大鏡看邊角 | 好球帶範圍、擦邊也算好球 |
| 線審 | 俯瞰邊線，看飛球落地點判界內／界外 | 界線屬於界內、看第一落地點 |
| 壘審 | 跑者與傳球搶一壘，判安全／出局，慢動作重播顯示時間差 | 封殺的判定方式 |

## 開發

原始碼在 `src/`，修改後執行 `node build.cjs` 產生單一 `index.html`（全部內嵌，約 1 MB）。

- `src/data.js`：來源、球隊階段、沿革關係、年度名錄、事件、年度數據、展櫃故事、題庫
- `src/app.js`：球場模型、時光劇場、族譜、彈出視窗、問答
- `src/eras.js`：歷史長廊九個展櫃的動畫劇本與播放器
- `src/games.js`：五個體驗遊戲
- `src/museum.js`：館內地圖、人物、NPC、尋路、展品視窗、集章、啟動
- `src/template.html`、`src/shell.html`、`src/styles.css`、`src/museum.css`

## 資料

- 查核截止：2026-10-16。2026 球季進行中，只收錄六隊名錄，不收錄賽果與冠軍。
- 25 張事件球票（已移除以單一球員引退為主角的事件）、37 個球隊名稱階段、74 筆聯盟年度名錄、1990–2025 觀眾數與年度冠軍。
- 不偏袒任何球隊：以聯盟整體變化為主線，冠軍與紀錄依年份平鋪列出，球衣顏色不分隊。
- 看台亮燈數 = 當年平均每場觀眾 ÷ 10,500 × 座位數，是示意比例。體驗區速度與動畫為示意，規則依一般棒球規則簡化。

## 修改紀錄（與 AI 的迭代）

1. **Codex 版**：功能多但雜，文字偏免責說明。使用者認為未達標準。保存在 `codex-version/`。
2. **故事捲動版**：九局捲動敘事＋球場看板。使用者回饋：「這也沒有互動性」。
3. **互動球場版**：球場模型＋九局動手任務。使用者回饋：仍差很多——想要「逛博物館的感覺、有小人可以亂走、能體驗打擊投球當主審線審、動畫式的介紹」，並指出結尾聚焦周思齊不及格，因為網站是給所有球迷的。
4. **博物館版**：改成可走動的博物館地圖；九局任務變成歷史長廊的展櫃；新增五個體驗遊戲、冠軍獎盃牆、NPC 與集章護照；移除周思齊相關內容，第九局改以全聯盟年度進場人次與 12 強為結尾；冠軍事件改用中立標題。使用者回饋：展櫃裡「舊隊名配新隊名」這類任務，不認識中職的人答不出來，希望像動畫一樣呈現傳承。
5. **動畫展櫃**（目前）：九個展櫃全部改為免答題的動畫：交棒時旗子原地翻面、傳承鏈逐格出現並有金球滾過、整併時兩面旗飛在一起合成一面、解散時旗子降下、觀眾人數與大數字同步變化；最後一幕把 1990–2025 快轉一遍。

1. 在 GitHub 建立儲存庫 `taiwan-baseball-time-machine`
2. 上傳 `index.html`（只需要這一個檔案即可運作）
3. Settings → Pages → Branch 選 `main`、資料夾 `/ (root)` → Save
